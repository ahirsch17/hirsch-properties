This is a demo website for a fictional or future property leasing company, built to showcase features commonly found in professional real estate platforms. It supports property browsing, tour scheduling, lease application, and direct contact with a leasing agent.

🔹 Note: All property listings are sample data for demonstration purposes only.

💡 Features
	•	Front-end built with responsive design principles
	•	Tour booking logic includes double-booking prevention
	•	Confirmation emails were sent to both user and leasing agent (when active)
	•	Designed to simulate a functional leasing experience from start to finish

⚠️ Current Limitations

Due to free-tier resource limits (e.g. Render and free SQL databases), bookings are no longer stored live. When active, all booking and cancellation flows were tested and functioned as expected.
The lease application form is under construction and will be integrated in a future update.

🛠 Future Plans

In the future, this project will be updated with more sustainable back-end resources and full feature support, including persistent data storage and full lease application flow.
